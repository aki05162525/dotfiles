# キーボード操作メモ

このファイルは AI が読むための記録。利用者は読まず、操作を忘れたらチャットで AI に聞く。AI は、質問への答えを必ずチャットの返答に書き、あわせてこのファイルを更新する。

マウスを使わずに操作するために覚えたショートカットと、自分で割り当てたキーを記録する。
AI に聞いた内容は実際に試してから書く。

## 方針

- キーボードは HHKB Professional HYBRID Type-S(30周年記念モデル)。キーマップは本体に保存されるので、変更したらこのファイルに記録する。
- Windows と Mac のショートカットの違い(`Ctrl+C` と `Cmd+C` など)は揃えず、それぞれの OS の流儀で使い分ける。

## HHKB のキーマップ

キーマップ変更ツールで本体に書き込んでいる内容(2026-11-21 時点)。キーマップを変えたらここも更新する。
ツール上で青く表示されているキー(既定から変えたキーと思われる)を中心に書く。

### DIP スイッチ

すべて OFF(Down)。工場出荷時の設定のまま。

| SW | 役割 | 現在 |
|---|---|---|
| 1, 2 | モード選択(両方 OFF = HHK モード。Win / Mac モードもある) | OFF, OFF → HHK モード |
| 3 | Delete キーを BS にする | OFF |
| 4 | 左側の修飾キーの機能を変える | OFF |
| 5 | 修飾キー(◇ と Alt)を入れ替える | OFF |
| 6 | 省電力(OFF で有効) | OFF → 省電力有効 |

スリープまでの時間は 30 分。

### 標準レイヤー

- 最下段は左から `Fn` / `右 Alt` / `Space` / `◇`(Windows キー、Mac では Cmd) / `左 Alt`。左下を Fn にしているので、◇ は右側にだけある。
- 右 Alt は Aqua Voice(音声入力)のショートカット。一番よく使うので、左親指ですぐ押せるスペースの左に置いている(2026-11-21 に一番右下から移した)。
- 指の割り当て: 音声入力 = 左親指、Windows キー = 右親指、`Alt+Tab` の Alt = 右親指を伸ばす、Fn = 左手小指。
- Tab 行の右端は `BS`。
- 右 Shift の右隣は `Fn`。

### Fn レイヤー(Fn を押しながら)

| キー | 割り当て |
|---|---|
| 数字行 `1`〜`=` | `F1`〜`F12` |
| `\` / `` ` `` | `Ins` / `Del` |
| `I` / `O` / `P` | `PrintScreen` / `ScrollLock` / `Pause` |
| `[` / `]` | `Home` / `End` |
| `A` / `S` / `D` | 音量 下げる / 上げる / ミュート |
| `H` / `J` / `K` / `L` | `←` / `↓` / `↑` / `→`(Vim と同じ並び) |
| `;` / `'` | `PgDn` / `PgUp`(J / K と同じく左が下、右が上) |
| `,` / `.` | `End` / `PgDn` |
| `/` | スクリーンショット(修飾キー付きの `S`) |
| 右の `◇` | `Stop` |
| `Q`、Control、右 Shift、左下 Fn とスペース左の位置 | 無効 |

## T3 Code

キー設定は `~/.t3/userdata/keybindings.json`。

| キー | 動作 |
|---|---|
| `PgDn` / `PgUp`(HHKB: `Fn+;` / `Fn+'`) | 会話を上下にスクロールする。入力欄にフォーカスがあっても効く |
| `Ctrl+P` | ファイル名で検索して開く(`filePicker.toggle`) |
| `Ctrl+Shift+F` | プロジェクト内の文字列を検索する(`projectSearch.toggle`) |
| `Ctrl+W` | 右側のパネルを閉じる(`rightPanel.close`) |
| `Ctrl+K` | コマンドパレットを開く(`commandPalette.toggle`) |
| `Ctrl+U` | 使用量(usage)の画面を開く(`usage.open`)。開いたあとは `C` でコスト、`T` でトークン、`L` で上限を切り替える |
| `Ctrl+Shift+M` | モデルを切り替える(`modelPicker.toggle`) |
| `Ctrl+Shift+E` | エフォートを切り替える(`composer.effort`)。相談用スレッドは Sonnet 5.5 + `medium` が目安 |
| `F6` / `Shift+F6`(HHKB: `Fn+6`) | フォーカスを次 / 前の領域へ移す。開いたファイルをスクロールするときは、これでファイル側へ移してから `PgDn` / `PgUp` |
| `Ctrl+Shift+P` | 今のスレッドをピン留めする(`thread.pin`) |
| `Ctrl+1`〜`Ctrl+9` | サイドバーの N 番目のスレッドへ移る(`thread.jump.N`) |

Mac では `Ctrl` の代わりに `Cmd`(設定ファイル上の `mod`)。

## Chrome

| キー | 動作 |
|---|---|
| `Ctrl+W` | 今のタブを閉じる |
| `Ctrl+Shift+W` | 今のウィンドウをタブごと閉じる |
| `Ctrl+Shift+T` | 閉じたタブ(ウィンドウ)を開き直す |
| `Ctrl+T` | 新しいタブを開く |
| `Alt+←` / `Alt+→`(HHKB: `Alt+Fn+H` / `Alt+Fn+L`) | 前のページへ戻る / 進む。Alt は一番右下の左 Alt を使う(スペース左の右 Alt は音声入力) |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 右 / 左のタブへ移る |
| `Ctrl+1`〜`Ctrl+8` / `Ctrl+9` | N 番目のタブ / 一番右のタブへ移る |
| `Ctrl+Shift+M` | プロフィールのメニューを開いて切り替える |
| `Ctrl+L` → ブックマーク名の一部 → `↓` → `Enter` | アドレスバーからブックマークを検索して開く(一番早い)。`@bookmarks` + `Tab` で候補をブックマークだけに絞れる |
| `Alt+Shift+B` | ブックマークバーの最初の項目にフォーカスする。`←` `→` で選んで `Enter` で開く |
| `Ctrl+Shift+O` | ブックマークマネージャーを開く |
| `Ctrl+D` | 今のページをブックマークに追加する |
| `Ctrl+Shift+B` | ブックマークバーを表示 / 非表示にする |
| `F6`(HHKB: `Fn+6`) | フォーカスをアドレスバー、ブックマークバー、ページ本体の順に移す。PDF などがスクロールできないときは、これでページ本体へ移してから `PgDn` / `PgUp` |

Mac では `Ctrl` の代わりに `Cmd`。

起動時のプロフィール選択画面は表示しない設定にしている。前回のプロフィールで開くので、切り替えは `Ctrl+Shift+M` で行う。

## Windows: エクスプローラー

| キー | 動作 |
|---|---|
| `Win+E` | エクスプローラーを開く |
| `Ctrl+L`(または `Alt+D`) | アドレスバーにフォーカスする。`shell:downloads` と打って `Enter` でダウンロードへ移る |
| `Win+R` → `shell:downloads` → `Enter` | ダウンロードを直接開く |
| ファイル名の先頭の文字を打つ | その文字で始まるファイルへ移る |
| `↑` / `↓`、`Home` / `End` | ファイルを選ぶ、先頭 / 末尾へ移る |
| `Enter` | 開く |
| `Alt+↑` / `Alt+←` | 1つ上のフォルダー / 前のフォルダーへ戻る |
| `Ctrl+F`(または `Ctrl+E`) | 今のフォルダー内を検索する |
| `F6` / `Tab` | アドレスバー、左のナビゲーション、ファイル一覧などの間でフォーカスを移す |

## Windows: アプリ間の移動(フォーカスの切り替え)

| キー | 動作 |
|---|---|
| `Alt+F4` | 今のウィンドウを閉じる(どのアプリでも使える) |
| `Alt+Tab` | 直前に使っていたウィンドウへ戻る。2つのアプリを行き来するだけならこれで足りる |
| `Win+数字` | タスクバーにピン留めした N 番目のアプリへ移る。起動していなければ起動する。同じアプリのウィンドウが複数あるときは、押すたびに切り替わる |

タスクバーのピン留め順を固定すると、`Win+数字` で狙ったアプリへ一発で移れる。

| キー | アプリ |
|---|---|
| `Win+1` | Chrome |
| `Win+2` | Slack |
| `Win+3` | T3 Code(名前の「3」に合わせている) |

操作がわからないときは `Win+3` → `Ctrl+1` で、ピン留めした相談用スレッドを開いて AI に聞く。

## Chrome: Vimium C(拡張機能。2026-11-21 に導入)

ページ本体にフォーカスがあるときだけ効く。入力欄では効かないので `Esc` で抜ける。キーは Vimium の既定値で、実機での確認はまだ。`?` で実際の一覧が出る。

| キー | 動作 |
|---|---|
| `f` | リンクにヒント文字を出し、その文字を打ってクリックする |
| `F` | 同じヒントを、新しいタブでリンクを開く動作にする |
| `j` / `k` | 下 / 上へスクロールする |
| `d` / `u` | 半ページ下 / 上へスクロールする |
| `gg` / `G` | ページの先頭 / 末尾へ移る |
| `H` / `L` | 前のページへ戻る / 進む |
| `J` / `K` | 左 / 右のタブへ移る |
| `x` / `X` | タブを閉じる / 閉じたタブを開き直す |
| `t` | 新しいタブを開く |
| `o` / `b` | アドレス入力欄を開き、URL・履歴・ブックマークを検索して開く / ブックマークだけを検索して開く |
| `/` → 文字 → `Enter`、`n` / `N` | ページ内を検索する、次 / 前の一致へ移る |
| `gi` | 最初の入力欄にフォーカスする |
| `yy` | 今のページの URL をコピーする |
| `r` | ページを再読み込みする |
| `Esc` | 入力欄やヒント表示から抜ける |
| `?` | キーの一覧を表示する |

## Windows: 仮想デスクトップ

| キー | 動作 |
|---|---|
| `Ctrl+Win+Shift+←` / `Ctrl+Win+Shift+→` | 今のウィンドウを左 / 右の仮想デスクトップへ移す(2026-11-21 に動作を確認) |
| `Win+Ctrl+←` / `Win+Ctrl+→` | 左 / 右の仮想デスクトップへ切り替える(ウィンドウは動かない) |
| `Win+Ctrl+D` | 新しい仮想デスクトップを作る |
| `Win+Ctrl+F4` | 今の仮想デスクトップを閉じる |
| `Win+Tab` | タスクビューを開く |

## Windows: ウィンドウ管理

| キー | 動作 |
|---|---|
| `Win+Shift+←` / `Win+Shift+→` | ウィンドウを左右の別モニターへ移動する(サイズと位置関係を保つ) |
| `Win+←` / `Win+→` | 画面の左半分 / 右半分にスナップする。続けて押すと隣のモニターへ移る |
| `Win+↑` | 最大化する |
| `Win+↓` | 最大化を解除する。もう一度押すと最小化する |
| `Win+数字` | タスクバーの N 番目のアプリを起動・切り替える |
| `Alt+Tab` | ウィンドウを切り替える |
